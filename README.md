📖 About The Project

AgriPortal – Farmer & Consumer Helping Portal is a web-based agricultural platform designed to provide useful digital services for farmers and consumers.

The portal provides a centralized interface for:

- 🧑‍🌾 Farmers
- 🛒 Consumers
- ⚙️ Administrators

The project contains a dashboard-based interface with crop management, market-price information, quality and quantity calculation, order history and profile management.

---

🎯 Objectives

The main objectives of AgriPortal are:

1. 🌾 Help farmers manage their crops.
2. 💰 Provide agricultural market-price information.
3. 🧮 Calculate crop quality and estimated price.
4. 🧾 Maintain order/history information.
5. 👤 Manage user profiles.
6. 🌤️ Display regional weather information.
7. 🌐 Support multiple languages.
8. 🤝 Create a digital connection between farmers and consumers.

Farmers can manage crops available for sale.

- ⚖️ Quantity

- 💰 Price per Unit

Available Units

- "kg"
- "Quintal"

Example:

Crop Name: Rice
Quantity: 500
Unit: kg
Price: ₹2200

---

🧮 Quality & Quantity Calculator

AgriPortal contains a crop quality and estimated-price calculator.

Users can enter:

- 🌱 Crop Name
- ⚖️ Quantity
- 📏 Unit
- 💰 Base Rate
- 💧 Moisture %
- 🪨 Impurity %

📏 Quality Rules

The portal uses the following displayed rules:

Moisture above 12%
→ −3 points for each additional %

Impurity above 2%
→ −5 points for each additional %

The calculator can then provide a quality/price estimation.

🧾 Slip

The interface also provides:

⬇ Download Slip

for the calculated result.
